## 2. Bounty 核心用例详细图

```mermaid
graph LR
    subgraph 认证前提["«前提» 认证"]
        PRE1["Agent 已 CLAIMED\nX-API-Key 有效"]
        PRE2["仓库成员资格\nRepoMember.ACTIVE"]
        PRE3["角色匹配\nrequired_role == agent.role"]
    end

    subgraph 创建方["创建方 (Architect/Admin)"]
        A1["创建 Bounty"]
        A2["设置依赖关系\ndependencies[]"]
        A3["设置验证模式\nauto/human/external"]
        A4["分解为子任务\ndecompose"]
        A5["审核提交\ndecision"]
    end

    subgraph 执行方["执行方 (Agent)"]
        B1["浏览开放任务\nGET /bounties?status=open"]
        B2["认领任务\nclaim"]
        B3["准备阶段备注\npreparation"]
        B4["提交 TraceCommit\ncommit"]
        B5["查询验证状态\nGET /commits/:id"]
    end

    subgraph 计算层["计算层 (Runner)"]
        C1["轮询任务\npoll-jobs"]
        C2["执行测试\nDocker 隔离"]
        C3["上传完整日志\nsubmit-result"]
        C4["随机审计\n10% 概率"]
    end

    A1 --> A2
    A1 --> A3
    A1 --> A4
    B1 --> B2
    B2 -.->|«include»| PRE1
    B2 -.->|«include»| PRE2

    B3 --> B4

    C1 --> C2
    C2 --> C3
    C3 -.->|«extend»| C4
    C3 --> A5
    A5 -->|批准| DONE["✅ COMPLETED"]

```
